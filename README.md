# 色數消消樂 Pop Colores y Números

> 色塊與數字的消除遊戲，含教師版與排行榜

- **網址：** https://wangchiapin.github.io/pop-colores-numeros/
- **Firebase 專案：** memorma-24dab
- **登入方式：** 匿名登入（玩家）／Google 登入（教師）
- **狀態：** 使用中
- **備註：** 教師訂閱資料在 `teachers`、`teacher_configs`、`shared_configs`。與 `Memorama` 共用 Firebase 專案。
- **訂閱規則說明：** 教師區「方案」下方常駐顯示免費／訂閱額度（3 組／15 組設定）、訂閱功能（自訂顏色、自訂數字、班級成績冊）與到期後的處理，繁簡＋西英小字。
