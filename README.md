- **Firebase 專案：** memorma-24dab（排行榜，匿名登入）；中心專案 subscription-48d3c（老師連結、班級成績）
- **老師端：** 都在「老師管理中心」https://wangchiapin.github.io/profesor/ （設定組、自訂顏色與數字、班級、成績簿、學習單）。遊戲裡只剩一顆「老師管理中心」按鈕；以前遊戲內的教師區、管理頁已刪除（步驟 5-3）。
- **狀態：** 使用中

## 學生連結（照常可用）

- 練習：`?c=<設定碼>`；班級：`?c=<設定碼>&class=<班級碼>`（成績回傳 `class_scores/{cid}_colores_{設定碼}_{暱稱雜湊}`，步驟 6-2：成績依設定組分開，班級排行只比同一組）
- 舊式網址 `?t=<編碼設定>` 也還能用（只限免費功能）

## ⚙️ 基本設定（三款共用）

存在 localStorage `hanziGames.settings`，格式與規則見 `corre/README.md`。色數的對應：

- `script`：繁／簡（介面中文、顏色字、數字鍵都跟著）
- `lang`：中＋西／中＋英／只有中文（`zh` = 以前的「輔助語言：無」）
- `phon`：拼音、注音、兩個都顯示、關 → 顯示在顏色按鈕、數字鍵、題目文字的上面。內建顏色與數字用程式內的台灣讀音表（`PY`，「一百、一千」的「一」唸 yì）；老師自訂顏色用設定裡的 `p`（中心編輯時自動帶出，可手改），沒有 `p` 就不顯示
- `rate`：慢／正常／快 → 0.45／0.65／0.85（和其他遊戲統一）
- 第一次會從舊的 `shushu_cfg`（simp、aux、rate）搬過來。玩法設定（玩法、格數、顏色組、數字範圍、顯示題目文字）仍存在 `shushu_cfg`，留在開始畫面
